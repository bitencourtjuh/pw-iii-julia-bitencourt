  <h2 style="color:#333;"> --- Sobre a Aula</h2>
  <p>
    Durante as aulas de <strong>Programação Web</strong>, estamos trabalhando com o 
    <strong>framework React</strong>, uma biblioteca JavaScript amplamente utilizada 
    para o desenvolvimento de interfaces de usuário modernas e dinâmicas.
  </p>

  <p>
    O React permite a criação de aplicações organizadas por meio de 
    <strong>componentes reutilizáveis</strong>, facilitando a manutenção, escalabilidade 
    e padronização do código.
  </p>

  <p>
    Além disso, proporciona uma melhor experiência ao usuário, pois realiza atualizações 
    rápidas na interface sem a necessidade de recarregar toda a página.
  </p>

  <hr>

  <h2 style="color:#333;"> --- Conteúdos Trabalhados</h2>

    <li> State (Estado)</li>
    <li> Estrutura de Projetos</li>
    <li> Renderização Dinâmica</li>
  </ul>

  <hr>

  <h2 style="color:#333;"> --- Objetivo</h2>
  <p>
    Desenvolver habilidades práticas no desenvolvimento front-end, utilizando tecnologias 
    modernas e preparando os alunos para o mercado de trabalho e para a criação de sistemas 
    mais eficientes e interativos.
  </p>
